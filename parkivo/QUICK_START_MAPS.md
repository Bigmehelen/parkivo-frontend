# 🚀 Quick Start - Enable Google Maps

## You Need to Enable 2 APIs

### 1️⃣ Maps JavaScript API (Required)
**What it does:** Shows the interactive map

👉 **https://console.cloud.google.com/apis/library/maps-backend.googleapis.com**

Click "ENABLE" → Wait 30 seconds

---

### 2️⃣ Geocoding API (Required)
**What it does:** Shows your real address instead of coordinates

👉 **https://console.cloud.google.com/apis/library/geocoding-backend.googleapis.com**

Click "ENABLE" → Wait 30 seconds

---

## Enable Billing (Required but FREE)

👉 **https://console.cloud.google.com/billing**

- Link a credit card (won't be charged)
- You get **$200 FREE credit every month**
- Maps usage: **28,000 FREE loads/month**
- Geocoding: **40,000 FREE requests/month**

---

## After Enabling

1. Wait 1-2 minutes
2. Refresh your browser (Ctrl+R)
3. The map should now work!

## Need Help?

Check browser console (F12) for error messages.

If still not working:
1. Clear browser cache
2. Wait 3-5 minutes after enabling
3. Make sure billing is enabled
4. Verify you're in the correct Google Cloud project
